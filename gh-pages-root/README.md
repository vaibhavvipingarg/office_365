# Salesforce Integration Add-in for Office 365

This repository contains the deployed version of the Salesforce Integration Add-in for Office 365.

## How to Use

1. Download the manifest-gh-pages.xml file
2. In Office Online (Word, PowerPoint, etc.), go to Insert > Add-ins
3. Choose "Upload My Add-in" and select the manifest file
4. The add-in will be loaded and available in your Office application

## Features

- Connect to Salesforce from Office 365 applications
- Insert Salesforce data into your documents
- Authenticate securely with OAuth
